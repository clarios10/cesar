Con el objetivo de identificar la causa por la cual el cifrado silencioso de BitLocker se aplica correctamente en equipos Lenovo, pero requiere intervención manual en algunos equipos HP, agradeceré su apoyo para realizar las siguientes validaciones y actividades.

1. Validación de prerrequisitos para BitLocker Silent Encryption

Favor de revisar en los equipos HP afectados los siguientes puntos:

Configuración del TPM

Ejecutar: PowerShell

Get-Tpm

Validar que los siguientes valores sean correctos:

TpmPresent : True

TpmReady : True

 

Configuración de UEFI y Secure Boot

Ejecutar: PowerShell

Confirm-SecureBootUEFI

 

El resultado debe ser:

 

True

 

Adicionalmente, revisar en BIOS:

TPM habilitado.
TPM State habilitado.
Secure Boot habilitado.
Modo de arranque UEFI.
Estado de BitLocker

Ejecutar: PowerShell

manage-bde -status

Get-BitLockerVolume

Validación de políticas de Intune

Confirmar que la política de BitLocker no requiera:

Startup PIN.
Startup Key.
Startup Key + PIN.
Cualquiera de estas configuraciones puede impedir el cifrado silencioso y provocar que el usuario deba iniciar el proceso manualmente.

Revisión de eventos

Validar los registros en:

Event Viewer

└ Applications and Services Logs

└ Microsoft

└ Windows

└ BitLocker-API

y

Microsoft-Windows-TPM-WMI

2. Validación de despliegue de Wallpaper mediante Intune

Para la implementación de fondos corporativos, favor de validar:

Requisitos de la imagen

Formato JPG, JPEG o PNG.
Resolución recomendada 1920x1080 o superior.
Relación de aspecto 16:9.
Validación de acceso a la imagen
